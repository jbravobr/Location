# Localização — app e API

> Projeto de localização com componentes de aplicativo e API, organizado em módulos separados.

## Organização

- `API/` — serviços e integrações da aplicação.
- `APP/` — aplicativo.
- `Components/` — projeto ou módulo `Components`.

Solução: [`Location.sln`](Location.sln).

## Tecnologias

C# e .NET.

## Como abrir

Abra [`Location.sln`](Location.sln) no ambiente de desenvolvimento compatível com a stack do projeto.
